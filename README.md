# California Housing Price Prediction

A regression project that uses a feed-forward neural network built with **PyTorch** to estimate median house values from the California Housing dataset.

## Project overview

The dataset contains 20,640 observations and 8 input features describing California housing districts. The target is the median house value, expressed by the dataset in units of **$100,000**.

## Workflow

1. Load the California Housing dataset with scikit-learn.
2. Split the data into training and test sets (80% / 20%).
3. Standardize input features using `StandardScaler`, fitted only on the training set.
4. Train a neural network with two hidden layers (64 and 32 neurons) using ReLU activations.
5. Optimize the model with Adam and Mean Squared Error (MSE).
6. Evaluate predictions using MAE, RMSE and R².
7. Save training curves and an actual-versus-predicted plot in `outputs/`.

## Technologies

- Python
- PyTorch
- scikit-learn
- NumPy
- Matplotlib

## Run locally

```bash
# Create and activate a virtual environment (optional but recommended)
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the project
python california_housing.py
```

The first run may need an internet connection to download the dataset through scikit-learn.

## Outputs

After execution, the script creates:

- `outputs/loss_curves.png`
- `outputs/actual_vs_predicted.png`

The evaluation metrics are printed in the terminal. They should be generated by running the code; no performance result is claimed in advance.

## Notes

- A fixed random seed is used to improve reproducibility.
- The scaler is fitted on training data only to prevent data leakage.
- The target values are kept in the original dataset scale ($100,000 units).
